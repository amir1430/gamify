# Feature Flags Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Operators create on/off flags in the console. Each flag has a sticky percentage rollout
and a per-flag tester list. Game clients read their own flags with `flags.get`.

**Architecture:**
- A new opt-in module `flags`, modeled on `restrict`. It owns two tables (`flags`,
  `flag_testers`), keeps an in-memory snapshot reloaded every `ReloadEvery`, evaluates with a frozen
  SHA-256 bucket, and serves the RPC `flags.get`.
- `flags/flagsadmin` adds one console view built on `admin.View`, guarded by a new
  `admin.PermFlags`.

**Tech Stack:** Go, pgx/v5, sqlc, goose (via `a.Migrate`), `realtime.JSON`, the admin `View` API,
`apptest` / `internal/admintest`.

**Spec:** `docs/superpowers/specs/2026-11-16-flags-design.md`

## Global Constraints

- Additive only (v1 is tagged): no committed migration edited, no exported API broken. All entries
  go in `CHANGELOG.md` under Unreleased, with upgrade notes.
- The module owns its migrations: goose table `goose_flags`, via `a.Migrate`.
- sqlc for every query, generated into `flags/internal/store`; never edit generated code (run
  `sqlc generate`).
- User identity only from the connection (`realtime.JSON`'s `userID`), never from a payload.
- The bucket hash is frozen: `SHA-256(key + ":" + decimal(userID))`, first 8 bytes big-endian
  uint64, `% 10000`. Its pinned vectors never change.
- Evaluation order: no flag → fallback; `enabled=false` → `false` (beats testers); tester → `true`;
  `bucket < percent*100` → `true`; else `false`.
- Key format `^[a-z0-9][a-z0-9_.-]{0,63}$`; keys are immutable. `percent` is 0..100. `type` is
  `bool` only.
- Flags never touch money, limits or `gameconfig`.
- Go is built test-first; the console UI needs no new frontend code (the generic view renders it).
- macOS builds: `CGO_LDFLAGS=-Wl,-ld_classic`.
- Integration tests need the Postgres env from README "Development"; without it they skip. A
  skipped test is not a pass: run them against Postgres.

## Review Focus

1. **Deleting a flag while clients are using it:** `flags.get` simply stops listing the key, and
   `Bool` returns the fallback. It must not return an error or a stale value after reload. Covered
   by `TestDeleteFallsBack` (Task 2).
2. **A tester ID that isn't a user, or the same ID twice in the tester list:** the first is
   refused with `ErrUnknownPlayer` (400 in the console), the second is stored once. Covered by
   `TestSetTesters` (Task 2).
3. **Two instances:** a change made on instance A reaches B's `flags.get` after B reloads, and a
   failed reload keeps the last snapshot rather than emptying it (which would switch every flag off
   for everyone). Covered by `TestReloadAcrossInstances` (Task 2).
4. **Turning a flag off and back on keeps its percent and testers:** off must not wipe them.
   Covered by `TestOffKeepsRollout` (Task 2).
5. **Uppercase, spaces or an empty key from the console:** refused with a readable 400, never
   stored. Covered by `TestCreateErrors` (Task 2) and the console test (Task 3).

```go
func TestBucketVectors(t *testing.T) {
	for _, c := range []struct {
		key  string
		user int64
		want uint64
	}{
		{"new_lobby", 1, 8077},
		{"new_lobby", 2, 183},
		{"new_lobby", 42, 8072},
		{"shop_button", 1, 4657},
		{"crash.new_lobby", 1000000, 4810},
		{"a", 9223372036854775807, 6088},
	} {
		if got := bucket(c.key, c.user); got != c.want {
			t.Errorf("bucket(%q, %d) = %d, want %d", c.key, c.user, got, c.want)
		}
	}
}

func TestValue(t *testing.T) {
	testers := map[int64]struct{}{7: {}}
	// user 2 has bucket 183 for new_lobby (in at 2%, out at 1%); user 1 has 8077.
	for name, c := range map[string]struct {
		e    entry
		user int64
		want bool
	}{
		"off":                {entry{key: "new_lobby", percent: 100, testers: testers}, 1, false},
		"off beats tester":   {entry{key: "new_lobby", percent: 100, testers: testers}, 7, false},
		"on 0% tester":       {entry{key: "new_lobby", enabled: true, testers: testers}, 7, true},
		"on 0% other":        {entry{key: "new_lobby", enabled: true, testers: testers}, 2, false},
		"on 2% in bucket":    {entry{key: "new_lobby", enabled: true, percent: 2}, 2, true},
		"on 1% out of bucket": {entry{key: "new_lobby", enabled: true, percent: 1}, 2, false},
		"on 100%":            {entry{key: "new_lobby", enabled: true, percent: 100}, 1, true},
	} {

			t.Errorf("%s: got %v", name, got)
		}
	}

// Raising the percent only adds players, and each step holds about that share.
func TestRolloutOnlyAdds(t *testing.T) {
	prev := map[int64]bool{}
	for _, p := range []int{0, 1, 10, 50, 100} {
		e, n := entry{key: "new_lobby", enabled: true, percent: p}, 0
		for u := int64(1); u <= 20000; u++ {
			in := e.value(u)
			if prev[u] && !in {
				t.Fatalf("user %d dropped at %d%%", u, p)
			}
			prev[u] = in
			if in {
				n++
			}
		}
		if got := float64(n) / 200; got < float64(p)-1.5 || got > float64(p)+1.5 {
			t.Errorf("%d%%: %.2f%% of users", p, got)
		}
	}
}
```

```go
var (
	ErrBadKey        = errors.New("flags: key must match ^[a-z0-9][a-z0-9_.-]{0,63}$")
	ErrExists        = errors.New("flags: a flag with this key exists")
	ErrNotFound      = errors.New("flags: no such flag")
	ErrBadPercent    = errors.New("flags: percent must be 0..100")
	ErrBadType       = errors.New("flags: type must be bool")
	ErrUnknownPlayer = errors.New("flags: unknown player")
)

type Config struct{ ReloadEvery time.Duration } // default 5s; negative refused by New

type Flag struct {
	ID               int64     `json:"id"`
	Key, Description string    // json "key", "description"
	Type             string    `json:"type"` // "bool"; "" on Create means "bool"
	Enabled          bool      `json:"enabled"`
	Percent          int       `json:"percent"`
	Testers          []int64   `json:"testers"` // sorted, never nil
	Version          int64     `json:"version"`
	UpdatedAt        time.Time `json:"updated_at"`
}

func New(pool *pgxpool.Pool, cfg Config) (*Service, error)
func Register(ctx context.Context, a *app.App, cfg Config) (*Service, error)
func (s *Service) Bool(userID int64, key string, fallback bool) bool
func (s *Service) For(userID int64) map[string]any
func (s *Service) List(ctx context.Context) ([]Flag, error) // ordered by key
func (s *Service) Get(ctx context.Context, id int64) (Flag, error)
func (s *Service) Create(ctx context.Context, tx pgx.Tx, f Flag) (Flag, error)
func (s *Service) Update(ctx context.Context, tx pgx.Tx, f Flag) (before, after Flag, err error)
func (s *Service) SetTesters(ctx context.Context, tx pgx.Tx, id int64, userIDs []int64) (before, after Flag, err error)
func (s *Service) Delete(ctx context.Context, tx pgx.Tx, id int64) (before Flag, err error)
func (s *Service) Applied(ctx context.Context)
```

What each piece does:
- **Snapshot:** `atomic.Pointer[map[string]entry]`, like `restrict`'s `rows`. `Load` returns an
  error. `reload` logs a failure with `slog` and keeps the last snapshot. `Applied` calls `reload`.
- **`Create`:** checks key, type and percent. A unique violation (`23505`) becomes `ErrExists`. It
  stores `f.Testers` when given, and returns the stored flag.
- **`Update`:** changes only description, enabled and percent, by `f.ID`. It locks the row
  (`FOR UPDATE`), bumps `version` and `updated_at`, and returns `ErrNotFound` for an unknown ID.
- **`SetTesters`:** replaces the list, dedupes it, and bumps `version` and `updated_at`. A foreign
  key violation (`23503`) becomes `ErrUnknownPlayer`, as in `restrict.go:299`.
- **`Delete`:** returns the deleted flag with its testers. Testers go by cascade.
- **RPC:** `Register` handles `flags.get` with `realtime.JSON`. The request is `struct{}` and the
  response is `struct{ Flags map[string]any `json:"flags"` }` from `s.For(userID)`. Off flags are
  listed as `false`.

### Task 3: Console view `flagsadmin` and `admin.PermFlags`

**Files:**

**Interfaces:**
- Consumes: Task 2's `flags.Service` methods, `flags.Flag` and errors.
- Produces: `func Register(adm *admin.Admin, s *flags.Service) error`; view name `flags`.

The view:
- Name `flags`, Title `Feature flags`, Group `Games`, Perm `admin.PermView`, no `UserFilter`.
- Columns: `id` (Int), `key` (Text), `description` (Text), `enabled` (Bool), `percent` (Int),
  `testers` (Int, the count), `updated_at` (Time). Summary: `key`, `enabled`, `percent`.
- `List`: `s.List`, one page, no `Next`. `Get` maps `flags.ErrNotFound` to `admin.ErrNotFound`.
  The detail row also has `tester_ids` (Strings, the IDs as decimal strings).
- Page action `new` (Perm `PermFlags`, Reason false): fields `key` (Text, Required), `description`
  (Text), `enabled` (Bool), `percent` (Int).
- Row action `edit` (Perm `PermFlags`): fields `description`, `enabled`, `percent`, prefilled from
  the row.
- Row action `testers` (Perm `PermFlags`): field `tester_ids` (Strings, Help "Player IDs who see
  this flag whenever it is on, even at 0%."). Each entry is parsed with `strconv.ParseInt`; a bad
  entry is `admin.BadInput("not a player ID: <entry>")`.
- Row action `delete` (Perm `PermFlags`): Confirm "Delete this flag? Games fall back to their
  default value for it.", TypeConfirm `"delete"`.
- Errors: `ErrBadKey`, `ErrExists`, `ErrBadPercent`, `ErrBadType` and `ErrUnknownPlayer` become
  `admin.BadInput(err.Error())`. `ErrNotFound` becomes `admin.Conflict("the flag was deleted")`.
- Every action's `After` calls `s.Applied(ctx)`. Every `Run` returns the `flags.Flag` before and
  after (`nil` before for `new`, `nil` after for `delete`). The `Flag` includes `key`, so the audit
  row records it.
- Not built: the player-page tab (the spec left it optional; dropped for v1).
